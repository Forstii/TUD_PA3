#TUD_PA3
This is a project work, which is part of the "Grundlagen der Digitalisierung" Module at the technical university Darmstadt.
The motivation behind this project is to learn the github versioning system,to learn how to filter and how to navigate datastructures and finally how to represent filtered data visually, to give end users compact and meaningful information.
The project will be based on an assignment-document consisting of 5 tasks.The tasks serve as a guide to accomplish the goals stated in the motivation.
